# ระบบรับสมัครเรียนออนไลน์ (โควตา) ประจำปีการศึกษา 2570
### วิทยาลัยเทคนิคท่าหลวงซิเมนต์ไทยอนุสรณ์
**สังกัดสำนักงานคณะกรรมการการอาชีวศึกษา กระทรวงศึกษาธิการ**

เว็บแอปพลิเคชันระบบรับสมัครนักเรียน นักศึกษา เข้าศึกษาต่อระดับประกาศนียบัตรวิชาชีพ (ปวช.) และประกาศนียบัตรวิชาชีพชั้นสูง (ปวส.) ประเภทโควตา ประจำปีการศึกษา 2570 ออกแบบตามมาตรฐานแบบแผนของสถานศึกษาและหน่วยงานราชการ สุภาพ เรียบง่าย น่าเชื่อถือ ใช้งานได้สมบูรณ์ทั้งบนคอมพิวเตอร์และโทรศัพท์มือถือ

---

## จุดเด่นและคุณสมบัติของระบบ (Key Features)

### 1. การออกแบบตามมาตรฐานหน่วยงานทางการศึกษา / หน่วยงานรัฐ
- **โทนสีสุภาพและน่าเชื่อถือ:** พื้นหลังสีเทาอ่อนและขาว ใช้สีกรมท่าทางการ (`#1F3A5F`) เป็นสีหลัก ไร้การไล่ระดับสีนีออน ไร้เงาหนาฟุ้ง และไม่ใช้อีโมจิที่ไม่จำเป็น
- **ฟอนต์ Sarabun (Google Fonts):** รองรับภาษาไทยมาตรฐาน อ่านง่าย สบายตา
- **เมนูเรียบง่าย 4 รายการ:** หน้าแรก / สมัครเรียน / ตรวจสอบสถานะ / เจ้าหน้าที่
- **ส่วนหัวเป็นทางการ:** ตราสัญลักษณ์วิทยาลัยเทคนิคท่าหลวงซิเมนต์ไทยอนุสรณ์ + ชื่อเต็มวิทยาลัย + สังกัดสำนักงานคณะกรรมการการอาชีวศึกษา
- **ท้ายหน้าครบถ้วน:** ระบุที่อยู่ เบอร์โทรสาร ช่องทางติดต่อ และระบุผู้พัฒนา "แผนกวิชาเทคโนโลยีคอมพิวเตอร์ วิทยาลัยเทคนิคท่าหลวงซิเมนต์ไทยอนุสรณ์"

### 2. ส่วนผู้สมัครเรียน (Applicants)
- **ฟอร์มใบสมัครตรงตามใบสมัครกระดาษจริง:** แบ่งเป็นหัวข้อเลขลำดับ 1-6
  - **ระดับการศึกษา:** ปวส. (สายตรง) / ปวส. (ม.6 หรือ ปวช. ต่างสาขา) / ปวช.
  - **ข้อ 1 ผู้สมัคร:** คำนำหน้า, ชื่อ-สกุล, วัน/เดือน/ปีเกิด (พ.ศ.), เลขประจำตัวประชาชน 13 หลัก
  - **ข้อ 2 บิดา:** ชื่อ-สกุล, อายุ, อาชีพ
  - **ข้อ 3 มารดา:** ชื่อ-สกุล, อายุ, อาชีพ
  - **ข้อ 4 ที่อยู่ปัจจุบัน:** บ้านเลขที่, หมู่, ซอย, ถนน, ตำบล, อำเภอ, จังหวัด (ครบ 77 จังหวัด), รหัสไปรษณีย์, หมายเลขโทรศัพท์ 10 หลัก
  - **ข้อ 5 ข้อมูลการศึกษาเดิม:** ระดับชั้น, โรงเรียนเดิม, ที่ตั้งโรงเรียน, ผลการเรียนเฉลี่ยสะสม (GPAX 5 ภาคเรียน), สาขาวิชาเดิม
  - **ข้อ 6 สาขาวิชาที่สมัคร:**
    - ระดับ ปวส. เลือก 1 สาขาวิชา
    - ระดับ ปวช. เลือก 2 ลำดับ (มีระบบป้องกันไม่ให้เลือกลำดับ 1 และ 2 ซ้ำกัน)
- **ระบบตรวจสอบความถูกต้อง (Validation):**
  - ตรวจสอบความถูกต้องของเลขประจำตัวประชาชน 13 หลักด้วย Modulo 11 Checksum Algorithm
  - ป้องกันการสมัครซ้ำด้วยเลขประจำตัวประชาชนเดิมในปีการศึกษา 2570
  - ตรวจสอบรูปแบบหมายเลขโทรศัพท์ 10 หลัก
  - ตรวจสอบเกรดเฉลี่ยสะสมในช่วง 0.00 – 4.00
- **การแนบเอกสารดิจิทัล (JPG/PNG/PDF ไม่เกิน 5 MB ต่อไฟล์):**
  - รูปถ่ายหน้าตรงขนาด 1 นิ้ว (บังคับ)
  - เอกสารแสดงผลการเรียนเฉลี่ยสะสม 5 ภาคเรียน (ปพ.1) (บังคับ)
  - สำเนาบัตรประจำตัวประชาชน หรือสำเนาทะเบียนบ้าน (บังคับ)
  - สำเนาเกียรติบัตร / ประกาศนียบัตรผลงาน (ไม่บังคับ)
- **การยินยอมข้อมูลส่วนบุคคล (PDPA Consent):** กล่องข้อความและเครื่องหมายยินยอมตาม พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562
- **การออกเลขที่ใบสมัครอัตโนมัติ:** รหัส `Q70-xxxx` (เช่น `Q70-0001`)
- **พิมพ์ / ดาวน์โหลดใบสมัครเป็นเอกสาร A4 (PDF):**
  - จัดรูปแบบตรงตามแบบฟอร์มราชการ
  - มีกล่องติดรูปถ่าย 1 นิ้วมุมขวาบน
  - ใช้ตัวเลขไทยในหัวเอกสารและปีการศึกษาตามต้นฉบับ (๒๕๗๐)
  - ตารางสรุปรายการหลักฐานประกอบการสมัคร
  - ช่องลงชื่อผู้สมัคร และช่องสำหรับเจ้าหน้าที่รับสมัครและทะเบียน

### 3. ระบบตรวจสอบสถานะผู้สมัคร (Status Check)
- ค้นหาด้วยเลขประจำตัวประชาชน 13 หลัก
- แสดงข้อมูลสรุปเท่าที่จำเป็นอย่างปลอดภัย ไม่เปิดเผยข้อมูลส่วนบุคคลเกินขอบเขต
- แสดงสถานะแบบเป็นทางการ:
  - `รอตรวจสอบ`
  - `เอกสารไม่ครบ`
  - `ผ่านการคัดเลือก`
  - `ไม่ผ่านการคัดเลือก`
  - `มอบตัวแล้ว`
- แสดงหมายเหตุจากเจ้าหน้าที่ทะเบียน (เช่น สิ่งที่ต้องแก้ไข หรือแจ้งวันเวลาสัมภาษณ์)
- **กรณีถูกส่งกลับแก้ไข (เอกสารไม่ครบ):** ผู้สมัครสามารถเลือกประเภทเอกสารและอัปโหลดไฟล์ใหม่ได้ทันทีจากหน้าจอนี้ โดยสถานะจะปรับกลับเป็น "รอตรวจสอบ" อัตโนมัติ

### 4. ส่วนเจ้าหน้าที่และงานทะเบียน (Staff Management Portal)
- **ระบบรักษาความปลอดภัยและแบ่งสิทธิ์:**
  - ผู้ดูแลระบบ (Admin)
  - เจ้าหน้าที่ทะเบียน (Registrar)
- **ตารางรายชื่อผู้สมัครแบบงานทะเบียน:**
  - หัวตารางสีกรมท่าเข้ม ข้อมูลอ่านง่าย ไม่ใช้การ์ดฟุ่มเฟือย
  - ค้นหาแบบเรียลไทม์ (เลขใบสมัคร, ชื่อ-สกุล, เลขบัตรประชาชน)
  - กรองตามระดับชั้น (ปวช./ปวส.) และสถานะ
- **ระบบตรวจเอกสารแบบรวมศูนย์ (Single-View Modal):**
  - ดูรูปถ่ายและเอกสารแนบของผู้สมัครได้ทันที
  - เปลี่ยนสถานะ พร้อมกรอกหมายเหตุแจ้งผู้สมัคร
  - ระบบบันทึกประวัติการเปลี่ยนสถานะ (Audit Trail: ใครเปลี่ยน เมื่อไร สถานะอะไร)
- **ระบบมอบตัวและออกรหัสนักศึกษา:**
  - สำหรับผู้สมัครที่ผ่านการคัดเลือก
  - บันทึกการมอบตัว พร้อมออกรหัสนักศึกษาอัตโนมัติ (เช่น `70201010001`)
- **แดชบอร์ดสรุปผลเชิงสถิติ:**
  - การ์ดสรุปยอดผู้สมัครทั้งหมด, รอตรวจสอบ, ผ่านการคัดเลือก, เอกสารไม่ครบ, มอบตัวแล้ว
  - กราฟแท่งสีกรมท่าล้วน (Monochromatic Palette) สรุปยอดผู้สมัครแยกตามสาขาวิชา
  - สรุป 5 อันดับโรงเรียนเดิมและจังหวัดที่มีผู้สมัครสูงสุด
- **การส่งออกข้อมูล (Export CSV/Excel):**
  - รูปแบบมาตรฐานงานทะเบียน
  - เข้ารหัส UTF-8 with BOM รองรับการเปิดใช้งานภาษาไทยใน Microsoft Excel อย่างสมบูรณ์
- **ระบบตั้งค่าส่วนกลาง (Settings):**
  - สวิตช์เปิด-ปิดระบบรับสมัครออนไลน์
  - กำหนดช่วงวันที่รับสมัคร
  - จัดการรายชื่อสาขาวิชา ปวช. และ ปวส. โดยไม่ฮาร์ดโค้ด
  - แก้ไขประกาศหน้าแรก
  - เชื่อมโยง Google Apps Script Web App URL

## ขั้นตอนการติดตั้งและเริ่มใช้งาน

กรุณาศึกษาคู่มือฉบับสมบูรณ์ได้ที่ [docs/SETUP_GUIDE.md](docs/SETUP_GUIDE.md)

### สรุปย่อ 4 ขั้นตอน:
1. **คัดลอกโค้ด Backend:** นำโค้ดจาก `backend/Code.gs` ไปวางใน Google Sheets (Extensions > Apps Script)
2. **สร้างฐานข้อมูล:** กดรันฟังก์ชัน `setupSystem()` ครั้งแรกใน Apps Script ระบบจะสร้าง 5 ชีตและโฟลเดอร์ใน Google Drive ให้ทันที
3. **Deploy Web App:** เลือก Deploy > New deployment > Web app (Execute as Me, Who has access: Anyone) แล้วคัดลอก Web App URL
4. **เปิดใช้งานหน้าเว็บ:** อัปโหลดขึ้น GitHub Repository และเปิด GitHub Pages จากนั้นนำ Web App URL มาใส่ในเมนู "เจ้าหน้าที่ > ตั้งค่าระบบ"
