## 1. โครงสร้างระบบและการทำงาน
ระบบประกอบด้วย 2 ส่วนหลัก:
1. **Frontend (เว็บแอปพลิเคชัน):**
   - พัฒนาด้วย HTML5, CSS3 และ JavaScript ตามมาตรฐานการออกแบบของหน่วยงานรัฐ/สถานศึกษา
   - โทนสีกรมท่าทางการ (`#1F3A5F`) ฟอนต์ Sarabun
   - มีระบบ Standalone / LocalStorage Mode ในตัว ทำให้สามารถเปิดทดสอบได้ทันทีแม้ยังไม่ได้ต่อ Google Apps Script
2. **Backend & Database (Google Cloud):**
   - **Google Sheets:** เป็นฐานข้อมูลหลัก ประกอบด้วย 5 ชีต (`Applicants`, `Documents`, `StatusLog`, `Staff`, `Settings`)
   - **Google Apps Script (`Code.gs`):** ทำหน้าที่เป็น REST API ให้บริการรับ-ส่งข้อมูล จัดการไฟล์ ตรวจสอบคุณสมบัติ และแจ้งเตือน
   - **Google Drive:** เป็นพื้นที่จัดเก็บไฟล์แนบ (รูปถ่าย 1 นิ้ว, ใบ ปพ.1, สำเนาบัตรประชาชน) โดยจัดเก็บในโฟลเดอร์เฉพาะอย่างปลอดภัย

## ขั้นตอนที่ 1: การเตรียม Google Sheets และ Google Apps Script

1. ไปที่ [Google Sheets](https://sheets.new) เพื่อสร้างสเปรดชีตเปล่าใหม่
2. ตั้งชื่อสเปรดชีตว่า:
   ```text
   ระบบรับสมัครเรียนโควตา 2570 - วท.ท่าหลวงฯ
   ```
3. คลิกเมนูบาร์ด้านบน: **ส่วนขยาย (Extensions)** > **Apps Script**
4. ลบโค้ดเดิมในไฟล์ `Code.gs` ทั้งหมด
5. เปิดไฟล์ `backend/Code.gs` ในโปรเจกต์นี้ คัดลอกโค้ดทั้งหมดแล้ววางลงใน Apps Script Editor
6. คลิกบันทึก (ไอคอนรูปแผ่นดิสก์ หรือกด `Ctrl + S`)

## ขั้นตอนที่ 2: การสั่งสร้างฐานข้อมูลอัตโนมัติ (1-Click Init)

ในโค้ด `Code.gs` มีฟังก์ชัน `setupSystem()` ที่จัดเตรียมไว้ให้สร้างชีตทั้ง 5 ตารางและโฟลเดอร์ Google Drive พร้อมรูปแบบทางการสีกรมท่าโดยอัตโนมัติ:

1. ในหน้า Apps Script Editor ด้านบนจะมีเมนูดรอปดาวน์เลือกฟังก์ชัน ให้เลือกฟังก์ชัน **`setupSystem`**
2. คลิกปุ่ม **เรียกใช้ (Run)**
3. Google จะขออนุญาตการเข้าถึงสิทธิ์ (Authorization Required):
   - คลิก **ตรวจสอบสิทธิ์ (Review permissions)**
   - เลือกบัญชี Google ของท่าน
   - หากขึ้นหน้าจอ "Google ยังไม่ได้ยืนยันแอปนี้" ให้คลิก **ขั้นสูง (Advanced)** > คลิก **ไปที่ ... (ไม่ปลอดภัย)**
   - คลิก **อนุญาต (Allow)**
4. รอระบบประมวลผลประมาณ 5-10 วินาที เมื่อเสร็จสิ้นจะเห็นข้อความ "การดำเนินการเสร็จสิ้น"
5. กลับไปดูที่ Google Sheets จะพบว่ามี 5 ชีตถูกสร้างขึ้นและจัดฟอร์แมตหัวตารางสีกรมท่าอย่างสวยงาม ได้แก่:
   - `Applicants` (ข้อมูลผู้สมัคร)
   - `Documents` (รายการเอกสารแนบและลิงก์ Drive)
   - `StatusLog` (ประวัติการเปลี่ยนสถานะ Audit Trail)
   - `Staff` (บัญชีผู้ใช้งานเจ้าหน้าที่)
   - `Settings` (การตั้งค่าระบบและรายชื่อสาขาวิชา)
   และใน Google Drive จะมีโฟลเดอร์ชื่อ `TC_Thaluang_Quota_2570_Uploads` ถูกสร้างขึ้นโดยอัตโนมัติ

## ขั้นตอนที่ 3: การ Deploy Google Apps Script เป็น Web App

1. ที่มุมขวาบนของหน้า Apps Script คลิกปุ่มสีน้ำเงิน **ทำให้ใช้งานได้ (Deploy)** > เลือก **การทำให้ใช้งานได้ใหม่ (New deployment)**
2. คลิกไอคอนรูปฟันเฟืองข้าง "เลือกประเภท" > เลือก **เว็บแอป (Web app)**
3. กรอกข้อมูลดังนี้:
   - **คำอธิบาย (Description):** `ระบบรับสมัครโควตา 2570 v1.0`
   - **ดำเนินการในฐานะ (Execute as):** `ฉัน (อีเมลของท่าน)`
   - **ผู้มีสิทธิ์เข้าถึง (Who has access):** **ทุกคน (Anyone)** *(สำคัญมาก เพื่อให้ผู้สมัครภายนอกสามารถส่งฟอร์มและตรวจสอบสถานะได้โดยไม่ต้องล็อกอินบัญชี Google)*
4. คลิก **ทำให้ใช้งานได้ (Deploy)**
5. ระบบจะแสดงหน้าต่างพร้อม **URL เว็บแอป (Web App URL)** ที่ลงท้ายด้วย `/exec`
   - ตัวอย่าง: `https://script.google.com/macros/s/AKfycb.../exec`
6. **คัดลอก (Copy) URL นี้เก็บไว้** สำหรับนำไปใส่ในเว็บ

## ขั้นตอนที่ 4: การนำขึ้น GitHub และเปิดใช้งาน GitHub Pages

### กรณีใช้ Git Command Line:
1. สร้างคลังข้อมูลใหม่ (New Repository) บน GitHub ของท่าน เช่น ชื่อ `thaluang-admission-2570`
2. ในโฟลเดอร์โปรเจกต์นี้ รันคำสั่งดังนี้:
   ```bash
   git remote add origin https://github.com/<บัญชี-GitHub-ของท่าน>/thaluang-admission-2570.git
   git branch -M main
   git push -u origin main
   ```
3. เมื่อ Push เรียบร้อยแล้ว ให้ไปที่หน้า Repository บน GitHub:
   - ไปที่แท็บ **Settings** > เมนูด้านซ้ายเลือก **Pages**
   - ในหัวข้อ **Build and deployment**:
     - Source: เลือก **Deploy from a branch**
     - Branch: เลือก **main** / โฟลเดอร์ **/(root)**
     - คลิก **Save**
4. รอ GitHub ดำเนินการประมาณ 1 นาที เว็บไซต์จะออนไลน์พร้อมใช้งานทันทีที่:
   ```text
   https://<ชื่อผู้ใช้>.github.io/thaluang-admission-2570/
   ```

## ขั้นตอนที่ 5: การเชื่อมต่อ Web App URL กับระบบ

ท่านสามารถเชื่อมโยง Web App URL ได้ 2 ช่องทาง:

### วิธีที่ 1 (ผ่านหน้าเว็บ - สะดวกที่สุด):
1. เปิดหน้าเว็บที่ขึ้นบน GitHub Pages
2. คลิกเมนู **เจ้าหน้าที่** ด้านบน
3. ล็อกอินด้วยบัญชี:
   - **ชื่อผู้ใช้:** `admin`
   - **รหัสผ่าน:** `admin2570`
4. คลิกแท็บ **ตั้งค่าระบบ**
5. ในข้อที่ 4 นำ Web App URL ที่ได้จากขั้นตอนที่ 3 วางลงในช่อง **Google Apps Script Web App URL**
6. คลิก **บันทึกการตั้งค่า**

### วิธีที่ 2 (ผ่านไฟล์ `js/app.js`):
เปิดไฟล์ `js/app.js` แล้วนำ URL ไปใส่ในตัวแปร `gasApiUrl` ในบรรทัดที่ 14:
```javascript
const DEFAULT_CONFIG = {
  gasApiUrl: 'https://script.google.com/macros/s/AKfycb.../exec',
  academicYear: '2570',
  ...
};
```
แล้ว Commit & Push ขึ้น GitHub อีกครั้ง

## การใช้งานระบบสำหรับเจ้าหน้าที่

### บัญชีผู้ใช้ตั้งต้น (Default Accounts):
| บทบาท | ชื่อผู้ใช้ (Username) | รหัสผ่าน (Password) | สิทธิ์การใช้งาน |
| :--- | :--- | :--- | :--- |
| **ผู้ดูแลระบบ (Admin)** | `admin` | `admin2570` | ตรวจสอบผู้สมัคร, เปลี่ยนสถานะ, มอบตัว, ออกรหัสนักศึกษา, ส่งออกข้อมูล, ตั้งค่าระบบ |
| **เจ้าหน้าที่ทะเบียน (Registrar)** | `registrar` | `reg2570` | ตรวจสอบผู้สมัคร, ตรวจเอกสาร, เปลี่ยนสถานะ, บันทึกมอบตัว, ส่งออกข้อมูล |

*(หมายเหตุ: สามารถเปลี่ยนรหัสผ่านหรือเพิ่มเจ้าหน้าที่ได้ในชีต `Staff` บน Google Sheets)*

### ฟังก์ชันเด่นสำหรับเจ้าหน้าที่:
1. **การกรองและค้นหา:** ค้นหาตามชื่อ-สกุล, เลขประจำตัวประชาชน 13 หลัก, เลขที่ใบสมัคร (`Q70-xxxx`) หรือกรองตามระดับ ปวช./ปวส. และสถานะ
2. **การตรวจเอกสารแบบรวมศูนย์:** คลิกปุ่ม "ตรวจเอกสาร / จัดการ" เพื่อเปิดดูรูปถ่าย 1 นิ้ว, ใบ ปพ.1, สำเนาบัตรประชาชน และเกียรติบัตร พร้อมตรวจสอบความถูกต้อง
3. **การส่งกลับแก้ไข (เอกสารไม่ครบ):** เมื่อเปลี่ยนสถานะเป็น "เอกสารไม่ครบ" พร้อมระบุหมายเหตุ ผู้สมัครสามารถเข้ามาอัปโหลดเอกสารใหม่ในหน้า "ตรวจสอบสถานะ" ได้ทันที
4. **การมอบตัวและออกรหัสนักศึกษา:** เมื่อผู้สมัครผ่านการคัดเลือก สามารถกดปุ่ม "บันทึกการมอบตัวและออกรหัสนักศึกษา" ระบบจะรันรหัสนักศึกษาประจำปี 2570 อัตโนมัติ (เช่น `70201010001`)
5. **การส่งออกข้อมูลงานทะเบียน:** คลิกปุ่ม "ส่งออก Excel / CSV" จะได้ไฟล์ CSV ภาษาไทย (เข้ารหัส UTF-8 with BOM) สำหรับเปิดใช้งานใน Microsoft Excel ได้ทันทีโดยข้อความไม่เพี้ยน
